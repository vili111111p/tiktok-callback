# tiktok-callback
Static GitHub Pages site used as the TikTok OAuth redirect URI for a private automation.
- `callback/` – shows the `code` returned by TikTok so it can be pasted into `gtareels tiktok-auth` (no tracking, no network calls)
- `privacy.html`, `terms.html` – required by the TikTok app review
Redirect URI: `https://<user>.github.io/tiktok-callback/callback/`
